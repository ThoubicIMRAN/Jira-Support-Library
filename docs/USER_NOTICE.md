# User Notice – Jira Support Library

**Effective Date:** November 2026

## 1. Purpose and Scope

Jira Support Library is a self-hosted internal application strictly intended for authorised **IT Operations** and support activities. Access is restricted to personnel with valid operational clearance.

## 2. Acceptable Use

By accessing or using this application, you agree to the following conditions:

- **Authorised Use Only:** You will use this tool exclusively for legitimate, job-related support and troubleshooting tasks.
- **Credential Security:** You are responsible for safeguarding your login credentials and session tokens. Sharing accounts or passwords with other individuals is strictly prohibited.
- **Data Confidentiality:** Any operational data, logs, or records accessed through this application must be handled in accordance with your organisation's internal data protection policies.

## 3. Security Reporting

If you suspect unauthorised access, credential compromise, or any technical vulnerability within the application, you must report it immediately to your system administrator or the **IT Operations** security team.

## 4. Enforcement

Unauthorised access, misuse of data, or violation of these terms is strictly prohibited and may result in immediate revocation of access and disciplinary action in accordance with internal company policies.
